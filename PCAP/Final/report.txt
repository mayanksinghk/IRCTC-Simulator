    Config Server
    -------------
    A config server (configuration server) is a specialized MongoDB instance that stores the metadata for the entire sharded cluster. first request comes here then this tells which server to go to get the required data.

    Shard Server
    ------------
    A shard server (or simply a "shard") is a standard MongoDB instance (mongod) that holds a subset of the total data within the sharded cluster.
